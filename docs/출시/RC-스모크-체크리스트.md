# RC 스모크 체크리스트 (실기기 · Android)

> Jira: `S15P11B209-632` · 작성 2026-08-02
> **언제 쓰나**: 원스토어·Play 에 APK/AAB 를 **제출하기 직전**, 그 빌드 그대로 실기기에서 한 번.
> 함께 볼 것: `infra/mobile/ONESTORE-HANDOFF.md`(빌드·등록) · `docs/인프라/푸시-실기기-검증.md`(푸시 상세)

## 0. 이 문서의 사용법

- 소요 **10~15분**. 담당자가 아니어도 이 문서만 보고 수행할 수 있게 썼다.
- **제출할 바로 그 APK** 로 한다. 디버그 빌드·다른 커밋으로 하면 의미가 없다.
- 항목마다 `기대`가 적혀 있다. 기대와 다르면 **제출을 멈추고** 아래 §7 에 기록한다.
- ★ 표시는 **아동 가드레일**(CLAUDE.md 9절) 항목이다. 여기서 하나라도 어긋나면 제출 불가.

### 준비물

| 항목 | 비고 |
|---|---|
| Android 실기기 (API 24+) | 에뮬레이터 불가 — 카메라·마이크·푸시 확인 때문 |
| 제출용 APK | `build-artifacts/app-release.apk` |
| 테스트 계정 | 카카오 또는 구글. **실아동 정보 사용 금지**(테스트 아동 프로필로) |
| 이전 버전 APK (선택) | §6 업데이트 설치 확인용 |

```bash
adb install -r build-artifacts/app-release.apk    # -r = 기존 위에 덮어쓰기
```

## 1. 설치와 첫 실행

- [ ] 설치가 오류 없이 끝난다 — 기대: `Success`
- [ ] 런처에 아이콘·앱 이름이 정상 표시된다
- [ ] 앱이 크래시 없이 첫 화면(`/auth/login`)까지 뜬다
- [ ] **네트워크를 끈 상태**로 한 번 켜본다 — 기대: 크래시 없이 오류 안내. 흰 화면·무한 로딩이면 실패

> ⚠️ 첫 실행에서 죽으면 그 뒤 항목은 전부 무의미하다. 여기서 멈추고 원인부터 잡는다.

## 2. 로그인과 온보딩

- [ ] 카카오 **또는** 구글 로그인이 성공한다
- [ ] 로그인 취소(뒤로가기)해도 앱이 죽지 않고 로그인 화면으로 돌아온다
- [ ] 앱을 **완전히 종료 후 재실행** — 기대: 다시 로그인하지 않고 홈(`/guardian/home`)으로 (토큰 저장·복원)
- [ ] 프로필 선택(`/profiles/select`)이 뜨고 보호자로 진입된다

## 3. 아동 등록과 동의 ★

- [ ] 아동 등록(`/guardian/children/register`)이 완료된다
- [ ] ★ 등록 과정에 **동의 화면**이 있고, 동의 없이는 진행되지 않는다
- [ ] ★ 설정 → 동의 관리(`/guardian/settings/consents`)에서 **동의 이력과 철회 경로**가 보인다

## 4. 아동 활동 핵심 경로 (가장 중요)

아동 모드 진입 → `/child/{id}/home`

- [ ] 활동 선택(`activity/select`) → 입력 방식(`input-method`) → 그리기(`drawing`) 순서로 진행된다
- [ ] **캔버스에서 선이 그려진다** — 지연·끊김이 없는지 함께 본다
- [ ] 그리는 중 **기기를 회전**한다 — 기대: **그리던 그림이 유지**된다
  (앱은 `configChanges` 로 회전을 직접 처리한다. 캔버스가 초기화되면 결함)
- [ ] 그리는 중 **홈 버튼으로 나갔다 복귀** — 기대: 작업 내용 유지 또는 임시저장 복원
- [ ] 완료 → 감정 선택(`emotions`) → 완료 화면(`complete`) 까지 도달한다
- [ ] AI 대화가 시작되고 **질문이 뜬다**
- [ ] 음성 답변 시 **마이크 권한 요청**이 뜨고, **거부해도 앱이 죽지 않는다**(선택형 답변으로 계속 가능)
- [ ] ★ **아동 화면 어디에도** 진단·위험 신호·분석 수치가 보이지 않는다 (아이가 보는 화면은 활동과 대화뿐)
- [ ] ★ 아동 모드에서 보호자 화면(설정·커뮤니티·리포트)으로 **빠져나갈 수 없다**

> 사진 업로드 경로를 쓴다면: 카메라 권한 요청 → 거부 시에도 크래시 없음 → 촬영본 업로드 성공까지 확인.

## 5. 보호자 확인 경로

- [ ] 활동 기록(`/guardian/activities`)에 방금 활동이 보인다
- [ ] 리포트(`/guardian/reports`)가 생성된다 (생성 중이면 대기 상태가 안내된다 — 무한 로딩 아님)
- [ ] ★ 리포트에 **AI 한계 고지**("진단이 아니라 관찰 참고 자료" 취지)가 **반드시** 포함돼 있다
- [ ] ★ 리포트 문구에 **진단·치료·검사** 같은 의료 표현이 없다
- [ ] 알림함(`/guardian/notifications`)이 열리고 목록이 보인다
- [ ] 커뮤니티(`/guardian/community`)가 열린다

## 6. 푸시·업데이트·탈퇴

- [ ] 알림 권한(`POST_NOTIFICATIONS`) 요청이 뜨고, **거부해도 앱이 정상 동작**한다
- [ ] 푸시 수신 — **상세 절차는 `docs/인프라/푸시-실기기-검증.md`**
  > ⚠️ **2026-08-02 현재 운영에서 푸시가 발송되지 않는다**(S15P11B209-774: `dodam-fcm` 시크릿 부재 + 발송 플래그 false). 774 해결 전에는 이 항목이 실패하는 것이 **정상**이며, 제출 차단 사유는 아니다. 774 반영 후 이 경고 문구를 지울 것.
- [ ] (업데이트 확인) 이전 버전이 깔린 기기에 새 APK 를 `adb install -r` — 기대: **데이터 유지된 채 갱신**
  > versionCode 가 이전 업로드보다 커야 스토어가 업데이트로 받는다(`ONESTORE-HANDOFF §3`).
- [ ] 설정 → 회원 탈퇴가 동작하고, 탈퇴 후 **같은 소셜 계정으로 재가입**이 된다 (S15P11B209-768 회귀 확인)
