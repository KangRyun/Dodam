## 4. 오늘 발견한 결함

### 4-1. versionCode 후퇴 (629에서 해소)

`BUILD_NUMBER`는 저장소 사실이 아니라 **잡에 딸린 상태**다. 07-29 브랜치 필터 사고로
develop 잡이 삭제·재생성되면서 실제로 되돌아갔다.

```
잡 디렉터리 생성 = 07-29 12:14   (사고로 재생성된 시각)
남아있는 빌드    = 1 2 3 4 5 6 7 8 9
707 이슈 본문    = "빌드 123~125 연쇄 원인"   ← 오늘 이전엔 123 이상
```

→ `infra/mobile/app-version.sh`로 산출을 옮김(`git rev-list --count HEAD`, 현재 1023).
   shallow clone에서는 커밋 수가 작게 나와 같은 사고를 재현하므로 **거부하고 빌드를 세운다.**

### 4-2. ⚠️ 회원 탈퇴가 아동 데이터를 지우지 않는다 — 미해소

`UserDeletionService.delete()`는 `userRepository.deleteById(userId)` 한 줄이고,
**`children` 테이블에는 users로 향하는 FK가 없다**(연결이 `guardian_child_relations` 경유).

- 아동 프로필 → **남는다**(보호자와 끊긴 고아 레코드)
- 그림 세션·대화·분석·리포트 → **남는다**(`child_id`가 RESTRICT)
- MinIO 그림 이미지·음성 → **남는다**(삭제 로직 없음, 373 미구현)
- 전문가 계정 → `expert_profiles`가 RESTRICT라 **탈퇴 자체가 실패**

CLAUDE.md 9절 *"회원 탈퇴 시 아동 데이터 함께 삭제"*와 어긋난다.
**별도 이슈 필요 — 스토어 선언보다 앞서는 서비스 요건 문제다.** 제안: P0/Highest.

### 4-3. 계정 삭제 요청 URL 부재 — 미해소

Play는 계정 생성이 가능한 앱에 **웹에서 접근 가능한 삭제 요청 URL**을 요구한다.
`/legal/delete`·`/legal/account-deletion`은 200을 주지만 **랜딩 페이지를 돌려주는 catch-all**이다.
있는 것처럼 보이는 쪽이 더 위험하다. `infra/nginx/html/legal/`에 `privacy`·`terms`와 같은 방식으로 추가하면 된다.
