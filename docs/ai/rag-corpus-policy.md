## 5. 보관·재현 정책

- **원문 파일은 저장소에 커밋하지 않는다** (git 비추적 — 바이너리·재배포 최소화 원칙, 가중치(*.pt)와 동일).
- **정본은 원문이 아니라 매니페스트다**: URL + SHA-256 체크섬 + 수집일을 기록해 두면 원문은 언제든 재다운로드로 재현된다. URL 소실 시 그 자료는 KB에서 제외하고 버전을 올린다(사본 재배포로 대응하지 않는다 — 라이선스 안전).
- 작업 사본 위치: 로컬 `_workspace/rag-corpus/`(git 비추적). 서버에는 원문을 두지 않는다 — 배포되는 것은 613이 만든 **인덱스 산출물**(npz+json)뿐이며, 가중치와 같은 경로(`ai-models` 볼륨 `/models/rag/`)로 나간다.
- 인덱스 안에는 청크 텍스트(발췌)가 들어간다 — §2를 통과한 자료만이므로 재배포 안전.

## 6. 매니페스트 — 613의 빌드 입력 (형식 확정)

`ai/rag/corpus-manifest.json` (git 추적 — 텍스트 메타뿐이라 커밋 가능):

```jsonc
{
  "knowledgeBaseVersion": "kb-2026.07-1",          // §7 규칙
  "sources": [
    {
      "sourceId": "kicce-mr2303",                  // 청크·출처 반환(614)의 키
      "title": "아동의 사회·정서 발달지원 서비스 현황분석 및 개선방안",
      "publisher": "육아정책연구소",
      "url": "https://repo.kicce.re.kr/…/MR2303.pdf",
      "license": "KOGL-1",                          // KOGL-1 | PD | CC0 | CC-BY 만 허용
      "licenseVerifiedAt": "2026-07-31",            // 자료 단위 실확인 일자 — 없으면 빌드 거부
      "collectedAt": "2026-07-31",
      "sha256": "…",                                // 원문 재현용
      "tags": ["DEV_STAGE"],
      "excludedSections": ["3.2 진단 도구 비교"]     // §1-2 비진단 선별 기록
    }
  ]
}
```

## 7. Knowledge Base Version 규칙

- 형식: `kb-<YYYY.MM>-<seq>` (예: `kb-2026.07-1`). 614가 `ObservationGenerationResult.knowledgeBaseVersion`으로 반환하는 값.
- **매니페스트가 바뀌면 버전이 바뀐다** (자료 추가/제거/excludedSections 변경 포함). 같은 매니페스트 → 같은 버전 → 같은 인덱스(613 재현성 조건).
- 갱신 주기: 정기 갱신은 두지 않는다(코퍼스는 느리게 변하는 일반 지식). 자료 변동 시에만 seq 증가, 월이 바뀌면 seq 리셋.
- 리포트에 기록된 KB Version으로 "그 리포트가 어떤 지식을 근거로 했나"를 사후 추적한다(재현성 — `modelVersion`의 프롬프트 버전과 같은 역할).
