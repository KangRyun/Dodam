### 1-2b. 해석 방침 갱신 (2026-08-03)

2026-07-17에 정한 "HTP를 점수화·검사 해석하지 않는다"는 **일부 완화됐다.** 현재 방침은
**"해석하지 않는다"가 아니라 "과대해석을 하지 않는다"** 이다.

| | 07/17 방침 | 08/03 이후 |
|---|---|---|
| 관찰에 근거한 해석 | 사실상 억제 | **허용** — 근거를 evidenceSummary 에 적고 여지 있는 표현으로 |
| 우려 소견의 보호자 노출 | 전량 전문가 채널 | **근거가 분명하면 보호자에게** |
| 단일 신호 추론·활동 밖 확대 | 금지 | 금지 (유지) |
| 진단명·점수·고정 특질 규정 | 금지 | 금지 (유지) |
| 부위의 상징 의미 | 금지 | **어휘 힌트로만** — '무엇을 눈여겨볼지' 고르는 데까지. 뜻 자체는 문장에 적지 않는다 |

**코퍼스 기준에 미치는 영향:** §1-2의 배제 규칙은 **그대로 유지된다.** 상징 의미를 문장에
적지 않기로 한 이상 해석 기준표는 여전히 불필요하고, 채택 자료 안의 해당 절도 계속 제외한다.
다만 §3의 `EMOTION_VOCAB`·`ART_ACTIVITY` 자료는 이제 '해석을 표현할 어휘'로도 쓰이므로,
재조사 시 관찰 어휘가 풍부한 산문을 우선한다.

> 상징 의미까지 쓰는 방향으로 다시 전환한다면 이 표와 §1-2를 함께 개정해야 한다.
> 반영 위치: `ai/prompts/report_common.txt`(1.7.0) · `ai/prompts/report_htp.txt`(1.5.0).

## 4b. 자체 저작 트랙 (2026-07-30 결정 — 1차 KB의 주 코퍼스)

외부 후보 전원 탈락에 따라 **팀이 직접 저작한 관찰 가이드 문서**를 1차 코퍼스로 쓴다.

- **라이선스 문제 0**: 자체 저작물(코드 `INTERNAL`) — 팀이 저작권을 보유, 발췌·임베딩·재배포 제약 없음.
- **내용 정합**: 서비스가 필요로 하는 것은 '비진단 관찰 어휘·부모 대화 가이드'이고, 이는 07/17 상담사 자문 방향과 같은 결이다 — 외부 학술 자료보다 서비스 톤에 맞는다.
- **관문**: 자체 저작 코퍼스는 **프롬프트 자산과 동급으로 검토**한다 — 운영 인덱스 배포 전 편주희(프롬프트·안전)·상담사 자문 교차 확인. 초안 상태는 매니페스트 `tags`와 별개로 문서 머리말에 표기.
- **보관 예외**: §5의 "원문 비보관"은 외부 자료(재다운로드로 재현) 얘기다. 자체 저작 원문은 재다운로드가 불가능하므로 **git으로 추적한다**(`ai/rag/corpus/` — 텍스트·비민감·팀 소유라 커밋 안전). sha256은 동일하게 기록해 인덱스와 원문의 정합을 검증한다.
- 출처 표기: `ragReferences`에 "도담 관찰 가이드" 식으로 노출 — 외부 권위처럼 보이지 않게 자체 문서임이 드러나는 제목을 쓴다(비진단 원칙과 일관).

## 5. 보관·재현 정책

- **원문 파일은 저장소에 커밋하지 않는다** (git 비추적 — 바이너리·재배포 최소화 원칙, 가중치(*.pt)와 동일).
- **정본은 원문이 아니라 매니페스트다**: URL + SHA-256 체크섬 + 수집일을 기록해 두면 원문은 언제든 재다운로드로 재현된다. URL 소실 시 그 자료는 KB에서 제외하고 버전을 올린다(사본 재배포로 대응하지 않는다 — 라이선스 안전).
- 작업 사본 위치: 로컬 `_workspace/rag-corpus/`(git 비추적). 서버에는 원문을 두지 않는다 — 배포되는 것은 613이 만든 **인덱스 산출물**(npz+json)뿐이며, 가중치와 같은 경로(`ai-models` 볼륨 `/models/rag/`)로 나간다.
- 인덱스 안에는 청크 텍스트(발췌)가 들어간다 — §2를 통과한 자료만이므로 재배포 안전.

## 7. Knowledge Base Version 규칙

- 형식: `kb-<YYYY.MM>-<seq>` (예: `kb-2026.07-1`). 614가 `ObservationGenerationResult.knowledgeBaseVersion`으로 반환하는 값.
- **매니페스트가 바뀌면 버전이 바뀐다** (자료 추가/제거/excludedSections 변경 포함). 같은 매니페스트 → 같은 버전 → 같은 인덱스(613 재현성 조건).
- 갱신 주기: 정기 갱신은 두지 않는다(코퍼스는 느리게 변하는 일반 지식). 자료 변동 시에만 seq 증가, 월이 바뀌면 seq 리셋.
- 리포트에 기록된 KB Version으로 "그 리포트가 어떤 지식을 근거로 했나"를 사후 추적한다(재현성 — `modelVersion`의 프롬프트 버전과 같은 역할).
