# 그림일기 학습 데이터 출처·동의·보관 기준

> Jira: `S15P11B209-605` (AI-P1-001) · 작성 2026-07-29
> 적용 범위: 그림일기(`ART_DIARY`)·HTP 활동에서 수집되는 아동 데이터의 **AI 학습 활용**
> 기준 문서: `docs/plans/2026-07-28-art-diary-service-contract.md` · `docs/database/저장소-아키텍처.md` · `docs/인프라/파일-수명주기-정책.md` · `V17__seed_consent_terms.sql` · CLAUDE.md 9절
> 대상 독자: AI(학습·프롬프트) · BE(동의·삭제) · Infra(보관·백업)

이 문서는 "**어떤 데이터를 · 무슨 근거로 · 어디에 얼마나 두고 · 언제 지우는가**"를 학습 관점에서 정의한다. 운영(추론) 목적의 데이터 취급은 각 계약 문서를 따르고, 이 문서는 **학습에만** 적용된다.

## 0. 이 문서가 확정한 것

1. **`AI_TRAINING` 동의가 AGREE인 아동의 데이터만 학습에 쓴다.** 동의가 없거나 철회된 아동의 데이터는 서비스 운영(추론·리포트 생성)에만 쓰고 학습셋에 넣지 않는다.
   `reason`: 학습은 목적 외 이용이다. 운영 분석 동의(`DRAWING_ANALYSIS`)로 학습까지 갈음하면 동의 범위를 넘는다. V17이 `AI_TRAINING`을 **선택** 약관으로 분리해 심어둔 이유가 이것이다.
2. **학습은 원본 저장소를 직접 읽지 않고, 추출한 "학습 스냅샷"으로만 한다.** 스냅샷마다 ID·추출일시·대상 아동 수·동의 버전을 기록한다.
   `reason`: 원본을 직접 학습에 물리면 삭제·철회가 학습 파이프라인과 뒤엉킨다. 스냅샷을 경계로 두면 "이 모델은 어느 시점 어떤 동의 범위의 데이터로 만들어졌는가"에 답할 수 있다.
3. **철회·탈퇴는 원본 삭제 + 스냅샷 제외 + 다음 재학습 반영까지가 처리 범위다. 이미 학습된 가중치에서 특정 아동의 기여를 소급 제거하는 것은 불가능하다.**
   `reason`: 기술적으로 불가하다는 사실을 문서에 남긴다. 그래서 1번(사전 동의)이 사실상 유일한 방어선이며, 동의 없는 데이터가 학습에 한 번이라도 들어가면 되돌릴 수 없다.
4. **외부 공개 데이터셋과 서비스 수집 데이터를 물리적으로 분리 보관하고, 섞은 학습셋에는 혼합 비율을 기록한다.**
   `reason`: 라이선스 의무(출처 표기)와 개인정보 처리 근거가 서로 다르다. 섞인 채로 관리하면 둘 중 강한 쪽 규제를 전체에 적용해야 한다.
5. **학습 가중치·데이터셋 바이너리는 git에 커밋하지 않는다.** (`ai/yolo_client.py` 주석의 기존 규칙을 정책으로 승격)
6. **아동 식별정보는 학습셋에 들어가지 않는다.** 파일명·경로·메타데이터에서 아동 ID/실명을 제거하고 별칭 또는 무의미 키로 대체한다.
   `reason`: 학습셋은 여러 환경(GPU 서버·노트북)으로 복제되며 삭제 큐가 닿지 않는다. 식별정보가 붙어 있으면 복제본마다 개인정보 파일이 된다.
7. **외부 추론 API에 보낸 데이터가 제공자 학습에 재사용되지 않는지는 미확인이다.** 확인되기 전까지 "외부 API 경유 데이터는 우리 통제 밖"이라고 가정하고, 아동 발화 원문·그림 원본을 학습 목적으로 외부에 보내지 않는다(§8-1).

## 3. 동의 기준 (V17 시드 실측 기준)

| term_code | 범위 | 필수 | 활성 | 학습에서의 의미 |
| --- | --- | --- | --- | --- |
| `AI_TRAINING` | CHILD | 선택(FALSE) | TRUE | **학습 활용의 유일한 근거.** 없으면 학습 금지 |
| `DRAWING_ANALYSIS` | CHILD | 선택(FALSE) | TRUE | 운영 분석 근거. 학습을 갈음하지 않는다 |
| `CHILD_PERSONAL_INFO` | CHILD | 선택(FALSE) | TRUE | 수집·이용 일반 근거 |
| `EXPERT_SHARING` | CHILD | 선택(FALSE) | TRUE | 열람 범위. 학습과 무관 |

현재 상태(2026-07-29):

- CHILD 동의를 **기록하는 흐름**은 `S15P11B209-655`로 앱에 반영됐다(아동 등록 화면의 동의 섹션, develop 머지 `9eac13c`). 그 전에는 `consent_records.subject_child_id` 이력이 만들어지는 경로가 없었다.
- CHILD 약관의 `is_required` flip은 아직 없다(V18·V19는 HTP 건). flip은 앱 배포 후에 한다.
- **따라서 이 문서 작성 시점에 `AI_TRAINING` AGREE 이력을 가진 아동은 사실상 없다. 학습셋 추출은 동의 이력이 쌓인 뒤에 시작한다.**

동의 확인 쿼리(학습셋 추출 전 필수 실행):

```sql
SELECT r.subject_child_id
  FROM consent_records r
  JOIN consent_terms t ON t.id = r.consent_term_id
 WHERE t.term_code = 'AI_TRAINING' AND t.target_scope = 'CHILD' AND t.is_active = TRUE
   AND r.action = 'AGREE'
   AND r.recorded_at = (SELECT MAX(l.recorded_at) FROM consent_records l
                         WHERE l.consent_term_id = t.id AND l.subject_child_id = r.subject_child_id);
```

최신 레코드가 `AGREE`인 아동만 대상이다. `WITHDRAW`가 최신이면 철회된 것으로 본다.

## 4. 비식별·최소수집 요건

학습 스냅샷을 만들 때 아래를 모두 적용한다.

- 파일명·디렉터리에서 `childId`·닉네임·세션 ID 제거 → 스냅샷 내부 순번 또는 해시로 대체
- 이미지 EXIF 전량 제거 (업로드 경로의 EXIF 제거는 `S15P11B209-661`에서 별도 진행 중 — 스냅샷 단계에서 한 번 더 확인)
- STT 텍스트는 개체명(이름·학교·지역·가족 호칭) 마스킹 후 반입
- 프롬프트·요청 로그에 아동 실명 대신 별칭 사용(`docs/AI모델선정.md` 규칙 승계)
- 스냅샷에 포함되는 최소 필드만 추출 — "일단 다 뽑아두고 나중에 고른다"를 금지한다

## 6. 계보(lineage) 기록 요건

학습을 시작하면 아래를 모델 산출물과 함께 남긴다. `S15P11B209-595`가 프롬프트에 대해 `promptVersion`을 저장하도록 만든 것과 같은 취지다.

```
snapshotId          : 학습 스냅샷 식별자
extractedAt         : 추출 시각
consentBasis        : AI_TRAINING v1 (동의 약관 코드·버전)
childCount          : 대상 아동 수 (개별 ID 아님)
externalDatasets    : QuickDraw <버전> · COCO <버전>
mixRatio            : 외부 : 서비스 수집 비율
modelVersion        : 산출 가중치 버전
```

`reason`: 나중에 "이 모델에 동의 없는 데이터가 들어갔는가"라는 질문을 받을 때, 기록이 없으면 아니라고 증명할 수 없다.

## 7. 금지 사항

- 동의 없는 아동 데이터의 학습 사용 — 예외 없음
- 관찰 리포트·AI 해석 결과를 정답 라벨로 재학습
- 학습셋·가중치의 git 커밋, 개인 클라우드 업로드, 팀 외부 공유
- 아동 그림·발화 원문을 외부 학습 목적으로 제공(§8-1 확인 전까지 금지)
- 학습셋을 커뮤니티·데모·발표 자료에 원본 그대로 노출 (필요 시 합성 예시 사용)
- 스냅샷 추출 로그에 아동 발화 원문·파일 바이트 기록

## 8. 확인·결정 필요

1. **외부 추론 API의 학습 재사용 여부** — GMS 경유 `gpt-4o-mini`·`whisper-1`·`gpt-4o-mini-tts`로 전송된 아동 데이터가 제공자 학습에 쓰이는지, 데이터 보존 기간이 어떻게 되는지 확인이 필요하다. `docs/AI모델선정.md`에 이 항목이 없다. → 확인 후 이 문서와 해당 문서 양쪽에 기록
2. **음성 원본의 학습 사용** — §1에서 일단 제외로 두었다. 목소리는 비식별이 성립하지 않는다는 판단인데, STT 정확도 개선에는 필요할 수 있다. 심리상담 자문·팀 결정 필요
3. **Google Drive 폴더 데이터의 출처** — 누가 어디서 수집했고 재배포·학습이 허용되는지 확인 필요. 확인되지 않으면 학습셋에서 배제
4. **스냅샷 보관기간 수치** — 파일 수명주기 정책의 보존기간 결정과 동시에 확정
5. **QuickDraw·COCO 라이선스 원문 확인** — 모델 카드 표기 문구 확정
