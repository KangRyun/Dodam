# 그림일기 리포트 V3 화면·PDF 설계

> 파일명은 기존 링크 호환을 위해 유지한다. V2는 기존 화면을 계속 사용하고 `schemaVersion >= 3`에서만 이 설계를 적용한다.

## 1. 읽기 목표

보호자는 다음을 구분해서 읽을 수 있어야 한다.

- 어떤 원자료를 사용했는가
- 그림과 대화에서 직접 확인된 것은 무엇인가
- 무엇은 이번 활동에 한정한 가능성인가
- 그 가능성을 다르게 설명할 수 있는가
- 다음에 아이에게 무엇을 물어볼 수 있는가
- 전체 질문·답변과 원본 음성을 어디서 확인하는가

단일 활동에는 심리 점수, 레이더 차트, 또래 비교, 진단·발달 판정을 표시하지 않는다.

## 2. 표시 순서

1. 완성 그림과 한 줄 이야기
2. `이번 기록의 자료 범위`
3. `그림에서 확인된 표현`
4. `이야기 구성 지도`
5. `아이가 직접 들려준 말`
6. `이번 활동에서 확인된 표현`
7. `그림과 대화에서 생각해 볼 수 있는 가능성`
8. `이번에는 확인하지 못했어요`
9. `오늘 마음 나누기`
10. `최근 활동 비교` — S15P11B209-1020에서 기준 충족 시만
11. 접이식 `전체 대화와 활동 상세`

빈 섹션은 숨긴다. 빈 곳을 일반적인 조언이나 심리 해석으로 채우지 않는다.

## 3. 자료 범위 카드

- 점수, 백분율, 진행 막대를 사용하지 않는다.
- `LIMITED`: `확인할 수 있는 자료가 적어요`
- `PARTIAL`: `확인된 내용 안에서 살펴봤어요`
- `RICH`: `이야기와 그림을 함께 살펴봤어요`
- 직접 발화·선택 답변·그림 관찰·건너뜀·확인 필요 STT 개수를 사실 그대로 표시한다.

`LIMITED`에서는 `SESSION_HYPOTHESIS` 카드와 그 섹션 제목을 모두 숨긴다.

## 4. 관찰과 이야기 지도

### 그림 관찰

`drawingObservations`는 이미지에서 직접 확인한 형태·배치·객체만 문장으로 보여 준다. 색·크기·위치만으로 정서나 성격을 해석하지 않는다. `childConfirmed=true`일 때만 `아이의 말로도 확인했어요`를 붙인다.

### 이야기 구성 지도

내부 enum은 다음 사용자 문구로 바꾼다.

| componentType | 사용자 문구 |
|---|---|
| `ACTOR` | 누가 |
| `EVENT` | 무슨 일 |
| `CHILD_ACTION` | 아이의 행동 |
| `OTHER_RESPONSE` | 상대의 반응 |
| `EMOTION` | 마음 |
| `WISH` | 바람 |
| `OUTCOME` | 그 뒤 |

`UNKNOWN` 항목은 빈 칸 대신 `아직 확인하지 못했어요`로 표시한다.

## 5. 확인된 표현과 제한적 가설

- `CONFIRMED_EXPRESSION`, `EXPLORE_NEXT`: `이번 활동에서 확인된 표현`
- `SESSION_HYPOTHESIS`: `그림과 대화에서 생각해 볼 수 있는 가능성`
- 가설은 대안 설명과 확인 질문을 같은 카드에 항상 함께 표시한다.
- `scopeText`를 생략하지 않는다.
- 가설 최대 2개. LIMITED에서는 0개.

## 6. 오늘 마음 나누기

질문, 공감 반응, 함께 해보기를 한 카드로 표시한다.

- `question`: 보호자가 그대로 물어볼 질문
- `responseGuide`: 아이 답을 판단하지 않고 받아 주는 반응
- `coRegulationAction`: 있을 때만 표시하는 함께 해보기
- `connectionType`: 내부 enum을 화면에 그대로 노출하지 않음
- `listeningTip`: 섹션 보조 문구

클라이언트가 서버 문구를 재작성하거나 새 조언을 생성하지 않는다.

## 7. 전체 대화와 음성

- 초기에는 접힌 상태다.
- 질문과 답을 한 쌍으로, 생성 시점 순서대로 표시한다.
- `VOICE` → `음성으로 답함`
- `OPTION` → `선택지에서 고름`
- `TEXT` → `글로 답함`
- `CORRECTION` → `음성 인식 내용을 고침`
- `SKIPPED` → `질문을 건너뜀`
- `audioAvailable && audioUrl != null && answerMessageId != null`일 때만 재생 버튼을 표시한다.
- 음성 참조가 삭제된 경우 텍스트는 유지하고 `원본 음성은 더 이상 재생할 수 없어요`를 표시한다.
- 401은 기존 토큰 갱신·로그아웃 정책, 404는 해당 음성만 재생 불가 처리한다.

## 8. 반응형·접근성

- 모바일은 한 열, 넓은 화면의 이야기 지도는 여러 열 Wrap
- 최소 본문 15sp, 섹션 제목 20sp
- 재생 버튼은 공통 `VoiceAnswerPlaybackControl`을 사용해 최소 터치 영역과 상태 낭독을 유지
- 색만으로 상태를 구분하지 않고 제목과 설명을 함께 표시
- 긴 텍스트와 textScale 2.0에서 가로 overflow 금지

## 9. PDF

- 화면과 같은 근거 순서로 출력한다.
- 전체 대화 텍스트를 포함한다.
- 재생 가능한 음성에는 `앱에서 음성 재생 가능`만 붙인다.
- 음성 URL, JWT, Storage Key와 음성 파일을 포함하지 않는다.
- 동작하는 리포트 딥링크가 마련되기 전에는 QR을 만들지 않는다.
- LIMITED에서 가설을 출력하지 않는다.

## 10. 최근 활동 비교

단일 활동 V3와 분리된 S15P11B209-1020 범위다.

- 최소 3개 활동, 서로 다른 2일 이상, 관련 아동 직접 구성 발화 2건 이상일 때만 반복 관찰 후보를 표시한다.
- 같은 아이의 이전 활동과만 비교한다.
- 실명 대신 보호자·형제자매·친구·선생님·기타 역할을 사용한다.
- 기준 미달 또는 조회 실패 시 최근 비교만 숨기고 단일 리포트는 유지한다.
