# 그림일기 리포트 V2 화면 설계

## 1. 설계 목표

보호자가 첫 화면에서 20초 안에 다음을 파악할 수 있어야 한다.

- 아이가 어떤 일을 중요하게 이야기했는지
- 아이가 그 상황에서 무엇을 했는지
- 누구의 반응이 중요했는지
- 어떤 감정·생각·바람을 자기 말로 표현했는지
- 집에서 어떤 대화를 이어 갈 수 있는지

단일 활동 리포트에서는 심리 경향, 성향 점수, 또래 비교, 진단 가능성을 보여 주지 않는다.

## 2. 정보 구조

### 2.1 상단 헤더

표시:

- `그림 속 이야기를 함께 돌아볼까요?`
- 활동 유형
- 활동 완료일
- 리포트 버전
- 한계 고지

한계 고지 예시:

> 이 리포트는 이번 그림과 대화에서 확인된 내용을 정리한 관찰 기록이에요. 아이의 평소 성격이나 심리 상태를 확정하는 결과는 아니에요.

### 2.2 핵심 이야기 카드

데이터: `diaryInsights.storySnapshot`

레이아웃:

- 왼쪽 또는 상단: 완성 그림
- 오른쪽 또는 하단: 이야기 제목과 1~2문장 요약
- 보조 태그는 아이 원문으로 확인된 경우에만 표시

태그 변환:

- `REAL` → `아이가 겪은 일이라고 이야기했어요`
- `IMAGINED` → `아이가 만든 이야기예요`
- `MIXED` → `경험과 상상이 함께 담긴 이야기예요`
- `UNKNOWN` → 태그 숨김
- `TODAY` → `오늘`
- `YESTERDAY` → `어제`
- `UNKNOWN` → 시점 숨김

내부 enum `REAL`, `TODAY`를 화면에 그대로 노출하지 않는다.

예시:

> **수학시험에서 100점을 받은 이야기**
> 아이는 수학시험에서 100점을 받고 엄마에게 자랑했으며, 엄마가 칭찬하고 장난감을 약속했다고 이야기했어요.

### 2.3 이야기 흐름

데이터: `diaryInsights.narrativeFlow`

표시 방식: 세로 또는 가로 타임라인. 2~5단계.

| stepType | 화면 라벨 | 권장 아이콘 |
|---|---|---|
| EVENT | 있었던 일 | 달력/장면 |
| CHILD_ACTION | 아이가 한 일 | 발자국/말풍선 |
| OTHER_RESPONSE | 함께 있던 사람의 반응 | 사람/대화 |
| EMOTION | 아이가 표현한 마음 | 표정 |
| WISH | 바랐던 것 | 별 |
| OUTCOME | 이어진 결과 | 체크 |

없는 단계는 표시하지 않는다. 빈 칸을 만들지 않는다.

### 2.4 아이가 직접 들려준 말

데이터: `diaryInsights.childVoiceItems`

최대 3~4개 인용. 같은 말을 다른 섹션에 다시 인용하지 않는다.

출처 태그:

- `OPEN_INVITATION` → `열린 질문에 답함`
- `CUED_INVITATION` → `앞 이야기에서 이어 말함`
- `FOCUSED_WH` → `구체 질문에 답함`
- `YES_NO` → `예·아니오로 답함`
- `MULTIPLE_CHOICE` → `선택지에서 고름`
- `CORRECTION` → `도담이의 인식을 바로잡음`
- `UNKNOWN` → 태그 숨김

`MULTIPLE_CHOICE`를 `아이가 스스로 말했다`로 표현하지 않는다.

음성 파일이 실제 존재할 때만 `음성 재생` 버튼을 표시한다. 텍스트만 있는데 비활성 버튼을 반복하지 않는다.

### 2.5 이번 활동에서 확인된 표현

데이터: `diaryInsights.sessionObservations`

제목은 `주요 심리 경향`이 아니라 **이번 활동에서 확인된 표현**으로 고정한다.

카드 수: 0~2개.

카드 구성:

- 짧은 제목
- 이번 활동 한정 설명
- 구체적인 근거 출처 요약
- 고정 범위 문구: `이번 활동에서 확인된 모습이에요.`

근거 표시 예시:

- `아이 음성 답변 2건`
- `열린 질문 답변 1건 + 그림 관찰 1건`
- `감정 카드 선택 1건`은 단독 강한 근거처럼 표시하지 않음

`근거가 어느 정도 있어요` 같은 모호한 배지는 사용하지 않는다.

### 2.6 보호자가 이어 갈 대화

데이터:

- `diaryInsights.caregiverQuestions`
- `diaryInsights.listeningTip`

질문 0~2개를 큰 버튼형 카드로 표시한다.

예시:

- `100점을 받고 엄마에게 자랑할 때 어떤 말을 했어?`
- `엄마가 잘했다고 말해줬을 때 어떤 말이 제일 좋았어?`

듣는 태도 예시:

> 점수만 되풀이하기보다 아이가 자랑하고 싶었던 마음과 엄마의 반응을 함께 들어주세요.

질문이 없으면 영역 전체를 숨긴다. 일반적인 육아 문구로 억지로 채우지 않는다.

### 2.7 상세 기록

초기에는 접힌 상태로 둔다.

포함:

- 객관적인 그림 관찰
- 전체 질문과 답변
- 활동 시간과 캔버스 지표
- STT 확인 필요 항목
- 질문·답변·건너뜀 수
- 모델/프롬프트 버전

메인 인사이트와 동일한 정보를 반복하지 않는다.

## 3. 현재 화면에서 변경할 항목

| 현재 영역 | V2 처리 |
|---|---|
| 주요 심리 경향 | `이번 활동에서 확인된 표현`으로 교체 |
| 대화 요약 | 핵심 이야기 카드와 타임라인에 통합 |
| 아이의 표현과 대화 요약 | `아이의 직접 표현` 한곳으로 통합 |
| 주제별 관찰과 문답 | 상세 기록으로 이동 |
| 객관적인 활동 기록 | 상세 기록으로 이동 |
| 질문/답변/건너뜀 숫자 카드 | 메인에서 제거, 상세에 표시 |
| 근거가 어느 정도 있어요 | 구체적인 출처 수와 방식으로 교체 |
| 자동 인식의 불확실 사물 | 보호자 화면에서 숨김 |

## 4. 빈 상태 규칙

- `diaryInsights == null`: 기존 리포트 화면으로 폴백
- `storySnapshot == null`: 핵심 이야기 카드 대신 `이번 활동의 대화를 충분히 정리할 근거가 아직 적어요` 한 줄 표시 후 상세 기록만 제공
- `sessionObservations == []`: 해당 섹션 숨김
- `caregiverQuestions == []`이고 `listeningTip == null`: 보호자 대화 영역 숨김
- `childVoiceItems == []`: 직접 표현 영역 숨김
- `narrativeFlow`가 1개 이하: 타임라인 대신 핵심 이야기 카드에 통합

## 5. 시각 디자인

색 역할을 네 가지로 줄인다.

- 파랑: 그림과 실제 이야기
- 보라: 이번 활동에서 확인된 표현
- 초록: 보호자가 이어 갈 대화
- 회색: 상세 기록·기술 정보

원칙:

- 카드 폭과 본문 폭을 통일
- 한 화면에 최대 두 개의 강조색
- 큰 빈 카드 안에 짧은 한 줄만 넣지 않음
- 태블릿 가로 화면에서 그림과 이야기 요약을 2열로 배치
- 모바일에서는 1열로 전환
- 본문 최소 16sp, 제목 최소 20sp
- 근거 태그는 색만으로 구분하지 않고 텍스트를 함께 표시

## 6. 누적 통계 화면: 2차 범위

단일 활동에는 그래프를 표시하지 않는다.

표시 기준:

- 1~2회: 그래프 없음
- 3~4회: `최근 기록`으로 표시, 경향이라는 표현 금지
- 5회 이상: `반복해서 등장한 내용` 표시 가능

권장 그래프:

### 6.1 이야기 주제 빈도

학교·배움, 가족, 친구, 놀이, 일상, 상상 이야기 등 역할/주제 빈도. 진단 점수가 아니다.

### 6.2 감정 표현 방식

- 아이가 직접 말함
- 선택 카드에서 고름
- 대화에서 확인되지 않음

긍정·부정 총점으로 만들지 않는다.

### 6.3 이야기 구성 요소 히트맵

최근 활동별로 사건, 아이 행동, 상대 반응, 감정, 바람, 결과가 대화에서 확인됐는지 표시한다.

이 값은 언어 능력 점수나 발달 판정이 아니라 `대화에서 나온 내용`이다.

### 6.4 대처·도움 요청 방식

어려운 사건에서만 집계한다.

- 스스로 해결을 시도함
- 보호자에게 말함
- 교사에게 도움을 요청함
- 친구와 대화함
- 확인되지 않음

### 6.5 반복해서 등장한 관계 역할

실명을 통계에 쓰지 않고 `보호자`, `형제자매`, `친구`, `선생님`, `기타` 역할만 집계한다.

### 6.6 활동 과정 추이

그린 시간, 실제 그린 시간, 멈춤·지우기 변화는 보조 그래프로만 제공한다. 집중력·충동성·자신감으로 해석하지 않는다.

## 7. 진단·선별 기능 경계

리포트 V2에는 다음을 넣지 않는다.

- ADHD·우울·불안장애 등의 진단명
- 심리 확률·백분위·위험 점수
- 색·크기·위치 하나에 고정된 심리 의미
- 한 번의 활동을 평소 성격으로 확장한 문장
- 또래 평균과 비교한 발달 판정

향후 발달·정서 선별을 제공하려면 검증된 별도 척도, 보호자 동의, 점수 해석 기준, 전문가 연결을 독립 기능으로 설계한다.
