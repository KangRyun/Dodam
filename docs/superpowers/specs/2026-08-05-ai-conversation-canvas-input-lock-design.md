# AI 대화 중 캔버스 입력 잠금 설계

## 목표

AI 질문 말풍선이 표시되는 동안 아동이 캔버스나 작업 도구를 잘못 조작하지 않고 대화에만 집중할 수 있게 한다. 말풍선이 사라지면 기존 캔버스 상태를 유지한 채 입력을 자동 복구한다.

## 상태 기준

화면에 실제 AI 질문 말풍선이 표시되는 조건을 단일 기준으로 사용한다. 질문 데이터가 로딩 중이거나 백그라운드에 존재하는 것만으로는 잠그지 않는다.

`conversationFocusMode = questionDisplayController.isVisible && activePointer == null && (canvasLocked || draftRestoreController.canDraw)`

기존 말풍선 가시성 계산과 같은 값을 재사용하여 말풍선과 입력 잠금 상태가 어긋나지 않게 한다.

## 잠금 범위

- 캔버스의 그리기, 채우기, 영역 지우기, 획 지우기 입력
- 툴바의 도구, 색상, 굵기, 실행 취소, 다시 실행, 전체 지우기
- 완료 CTA 및 튜토리얼 도움말
- 호버 커서와 굵기 미리보기

AI 말풍선 내부의 선택지, 음성 녹음, 다시 시도, 건너뛰기, 대화 종료 동작은 계속 사용할 수 있다. 시스템 뒤로가기는 사용자가 화면에서 빠져나올 수 있도록 유지한다.

## 입력 처리

1. 대화 집중 모드가 켜질 때 진행 중인 포인터나 획이 있으면 안전하게 취소하고 커서를 숨긴다.
2. 캔버스 자체의 `inputEnabled`에도 잠금 조건을 포함해 이벤트 핸들러 진입을 차단한다.
3. 툴바·캔버스·완료 CTA를 포함하는 작업 레이어에는 포인터 흡수 계층을 적용한다.
4. AI 말풍선은 흡수 계층보다 위에 배치하여 대화 입력만 전달한다.
5. 모드 해제 시 별도의 초기화 없이 기존 문서·도구·색상 상태를 그대로 사용한다.

## 오류 및 경계 조건

- AI 질문 전환 중 말풍선이 잠시 사라지면 기존 가시성 계약에 따라 잠금도 해제된다.
- 저장·동기화 같은 백그라운드 작업은 중단하지 않는다.
- 잠금 중 발생한 캔버스 포인터 이벤트는 문서 기록과 undo 이력에 남지 않는다.
- 대화가 끝나거나 말풍선이 닫히면 즉시 캔버스 입력이 복구된다.

## 검증 기준

- AI 말풍선 표시 중 캔버스 터치가 새 획을 만들지 않는다.
- AI 말풍선 표시 중 툴바와 완료 CTA가 동작하지 않는다.
- 말풍선 선택지와 음성 관련 동작은 계속 동작한다.
- 말풍선 종료 후 캔버스 입력과 툴바가 다시 동작한다.
- 잠금 전후 저장, 초안 복원, AI 질문 흐름의 기존 테스트가 유지된다.
