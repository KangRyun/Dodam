## 1. GMS — SSAFY GPT Meta Server (OpenAI 호환)

- **용도:** AI 캐릭터 대화(LLM), 음성 답변 STT, 질문 음성 TTS. OpenAI SDK 를 그대로 쓰되 `base_url` 만 GMS 로 바꾼다.
- **가입/발급:** SSAFY 에서 프로젝트별로 발급하는 공용 키. 별도 가입 절차 없이 **SSAFY 지원 포털에서 팀 키 수령** → base URL 과 함께 환경변수로 주입.
- **콘솔/엔드포인트:** `https://gms.ssafy.io/gmsapi/api.openai.com/v1`
- **필요한 값 (실값):**

  | 키 | 값 |
  |----|----|
  | `GMS_BASE_URL` | `https://gms.ssafy.io/gmsapi/api.openai.com/v1` |
  | `GMS_KEY` | `S15P12B209-0b3a5f04-5a12-47cf-9a76-9a266ca83814` |
  | `LLM_MODEL` (대화) | `gpt-5.4-mini` |
  | `REPORT_LLM_MODEL` (리포트) | `gpt-5.4` |
  | `STT_MODEL` | `whisper-1` |
  | `TTS_MODEL` / `TTS_VOICE` | `gpt-4o-mini-tts` / `fable` |

- **사용 위치:** AI 서버(`ai/`)가 GMS 를 호출, 백엔드는 `AI_*_MODE=http` 로 AI 서버를 호출. 근거·모델 선정은 `docs/AI모델선정.md`.

## 2. 카카오 로그인 (Kakao Developers)

- **발급 절차:**
  1. 애플리케이션 생성 → **앱 ID / REST API 키 / JavaScript 키** 확인.

  3. **Redirect URI 등록**(웹): `https://i15b209.p.ssafy.io/login/callback/kakao`
  4. 보안 → **Client Secret** 발급·사용 ON.

## 5. Firebase Cloud Messaging (FCM)

- **용도:** 그림 분석 완료 시 보호자에게 푸시 알림.
- **콘솔:** <https://console.firebase.google.com> → 프로젝트 → 프로젝트 설정 → 서비스 계정.
- **발급 절차:**
  1. Firebase 프로젝트 생성 + Android 앱(패키지명) 등록 → `google-services.json`(앱 빌드용).
  2. **서비스 계정 → 새 비공개 키 생성** → Service Account JSON 다운로드.
  3. 서버에 배치: `/etc/dodam/secrets/fcm-service-account.json` (`600 root:root`).
- **필요한 값:**

  | 키 | 값 |
  |----|----|
  | `APP_PUSH_FCM_ENABLED` | `true` |
  | `FCM_CREDENTIALS_HOST_PATH` | `/etc/dodam/secrets/fcm-service-account.json` |
  | `PUSH_DEVICE_TOKEN_ENCRYPTION_KEY` | `ctyLymCaa7jEuBUn/VgFLoMrXO7xezIZv2F/UYyv9VY=` (기기 토큰 암호화 — 변경 금지) |

> Service Account 개인키(JSON)는 git·문서에 넣지 않는다. 서버 파일 1벌만 유지(가드레일).

## 6. Let's Encrypt (TLS)

- **용도:** `i15b209.p.ssafy.io` HTTPS 인증서.
- **가입:** 없음 — 도메인 소유 확인(ACME HTTP-01, nginx `/.well-known/acme-challenge/`).
- **발급/갱신:** certbot. 최초 발급 후 자동 갱신은 호스트 crontab(`infra/cron/dodam-certbot-renew.sh`).
- **필요한 값:** 도메인만. 별도 키 없음.
