# 도담(dodam) 시연 시나리오

> 발표 시연 순서 — 화면별·동작별(클릭 위치 포함) 상세 안내
> 서비스: 아동 미술 심리 관찰·대화 AI · 대상: `https://i15b209.p.ssafy.io`
> 최종 갱신: 2026-08-10

## 0. 사전 준비 (시연 전 체크)

| 항목 | 준비 |
|------|------|
| 서버 | 라이브 확인 — `https://i15b209.p.ssafy.io/api/v1/*` 200, 컨테이너 healthy |
| 모바일 | APK 설치 — <https://i15b209.p.ssafy.io/download/dodam.apk> · **가로모드** 권장(그리기/대화) |
| 시연 계정 | 보호자 소셜 계정(카카오/구글) 로그인 준비 · 아동 프로필 1명 사전 등록 권장 |
| 웹 | 데스크톱 브라우저 — 커뮤니티/관리자 |
| 네트워크 | 음성(STT/TTS)·이미지 업로드가 있으니 안정적 회선 |

> **디바이스 흐름:** 보호자 모드는 하단 탭바(초록 톤), 아동 모드는 전체화면·탭바 없음(노란 톤·큰 버튼).
> 아동 모드 복귀는 **"길게 눌러 잠금 해제"** — 아이가 임의로 못 빠져나가게 하는 장치(시연 포인트).

## Part 1 — 보호자 온보딩 (모바일)

### 1. 앱 실행 → 로그인
- **화면:** 로그인(`/auth/login`)
- **클릭:** 화면 중앙 **[카카오로 시작하기]**(노란 버튼) 또는 **[구글로 시작하기]** 탭
- **동작:** 소셜 인가 → 콜백 → JWT 발급, 최초면 온보딩으로.
- **시연 포인트:** 소셜 로그인 실연동(mock 아님).

### 2. 권한/온보딩 → 프로필 선택
- **화면:** 권한 안내(`/auth/permissions`) → 프로필 선택(`/profiles/select`)
- **클릭:** 권한 **[허용]** → **[보호자]** 프로필 선택
- **동작:** 보호자 홈 진입.

### 3. 보호자 홈
- **화면:** 보호자 홈(`/guardian/home`) — 하단 탭바(홈/기록/커뮤니티/알림/설정)
- **시연 포인트:** 초록 톤 보호자 모드. 아동 카드·최근 활동·리포트 진입점.

### 4. 아동 등록 / 선택
- **화면:** 아동 선택(`/guardian/children/select`) → 등록(`/guardian/children/register`)
- **클릭:** **[+ 아동 추가]** → 이름·생년월일·성별 입력 → **[저장]** (또는 기존 아동 카드 탭)
- **동작:** 아동 프로필 생성/선택.

### 5. 활동 시작 → 아동 모드 진입
- **클릭:** 아동 카드의 **[활동 시작]**
- **동작:** **아동 모드(전체화면)** 로 전환 — 여기서부터 노란 톤·큰 버튼.

## Part 2 — 아동 활동 (아동 모드, 전체화면·가로) ★핵심

### 6. 활동 선택
- **화면:** 활동 선택(`/child/{id}/activity/select`)
- **클릭:** **[그림 검사(HTP)]** 또는 **[그림일기]** 중 하나 — 시연은 **HTP** 권장(단계·분석이 풍부)
- **동작:** 검사면 집→나무→사람 단계 흐름으로 분기.

### 7. 입력 방식 선택
- **화면:** 입력 방식(`/child/{id}/activity/input-method`)
- **클릭:** **[직접 그리기(캔버스)]**(과정 데이터 수집) 또는 **[사진 찍기/올리기]**
- **시연 포인트:** 캔버스 선택 시 획·색·시간이 **과정 데이터로 로깅**된다(더 상세한 분석).

### 8. 그리기 (캐릭터와 함께)
- **화면:** 그리기(`/child/{id}/activity/drawing`)
- **동작:** 캔버스에 그림 → **자동 저장**(stroke-batch·draft 주기 전송). HTP 는 집→나무→사람 순서 안내.
- **클릭:** 하단 팔레트에서 **색 선택**, 굵기 조절, 지우개. 그리는 중 캐릭터(곰돌이)가 반응.
- **시연 포인트:** 오프라인에서도 그리기 유지, 복귀 시 재전송. (네트워크에 강함)

### 9. 그림 완료
- **클릭:** 화면 우측/하단 **[다 그렸어요]** → 확인 다이얼로그 **[다 그렸어요]**
- **동작:** 최종 PNG 합성·업로드(`drawing-complete`) → **대화 단계(CONVERSING)** 로 전환.
- **주의(시연 팁):** 완료 버튼은 **획을 뗀 상태**에서 누른다(그리는 중이면 완료가 잠시 대기).

### 10. 캐릭터와 대화 (음성 + 선택 칩)
- **화면:** 대화(그리기 화면 위 대화 오버레이)
- **동작:** 캐릭터가 그림 근거로 질문(TTS 음성 재생) → 아이가 답한다.
- **클릭(두 가지 답변):**
  - **마이크 버튼**을 눌러 **음성**으로 답 → STT 로 텍스트화
  - 또는 하단 **선택 칩**(감정/보기) 탭
- **동작:** 질문–답변 반복(약 5문답, 연령별 난이도). **[대화 그만하기]** 로 조기 종료 가능.
- **시연 포인트:** "그리며 말하기"로 아동 발화를 이끄는 핵심 화면. 음성 STT/TTS 실연동.

### 11. 감정 선택
- **화면:** 감정 선택(`/child/{id}/activity/emotions`)
- **클릭:** 감정 6종(**기쁨·슬픔·화남·무서움·편안함·모르겠어**) **복수 선택** → **[다 골랐어요]**
- **동작:** 백그라운드 **분석 시작**.

### 12. 분석 중 → 활동 완료
- **화면:** 활동 완료(`/child/{id}/activity/complete`)
- **동작:** "분석 중" 안내 → 완료. 리포트는 보호자 모드에서 확인.
- **시연 포인트:** 위험 신호가 있어도 **아이 화면엔 배너 미노출**(보호자 모드에만).

### 13. 보호자 복귀 (잠금 해제)
- **클릭:** 화면 모서리/지정 영역을 **길게 누르기(long-press)** → 잠금 해제 → 보호자 모드 복귀
- **시연 포인트:** 아동이 임의 이탈 못 하게 하는 안전장치.

## Part 3 — 관찰 리포트 (보호자 모드)

### 14. 활동 확인 → 리포트 열람
- **화면:** 활동 확인(`/guardian/activities/{id}/confirm`) → 리포트(`/guardian/reports/{id}`)
- **클릭:** 알림 또는 기록 탭에서 방금 활동 → **[리포트 보기]**
- **동작:** 리포트 구성 — **"이런 모습이 보였어요 / 주요 대화 / 함께 확인해볼 점"** + 전문가 문의 유도.
- **시연 포인트(중요):**
  - 하단 **AI 한계 고지 고정** — "진단이 아닌 관찰 참고 자료".
  - 해석 문장마다 **근거(그림·발화·행동) + 확신도(강/중/약)** 표기.

### 15. 다운로드 / 전문가 연결
- **클릭:** **[PDF 다운로드]** / 대화 부분 다운로드, 또는 **[전문가에게 문의]** → 전문가 프로필 목록
- **시연 포인트:** 데이터 내려받기 제공 · 커뮤니티엔 분석/대화 **절대 비공개**.

## Part 4 — 커뮤니티 웹 (데스크톱)

### 16. 커뮤니티
- **화면:** `https://i15b209.p.ssafy.io/` → 로그인(카카오/구글/**네이버**) → 게시판
- **클릭:** 게시판 탭(보호자 이야기 / 칼럼 / 전문가 Q&A / 공지) → 글 열람 → **[글쓰기]**
- **시연 포인트:** 웹 소셜 로그인(code→token 서버 교환). **AI 분석/대화 내용은 커뮤니티에 노출되지 않음**.


## 돌발 상황 대비 (시연 팁)

| 증상 | 대응 |
|------|------|
| 그림 완료가 안 눌림 | 획을 완전히 뗀 뒤 누른다(그리는 중엔 완료 대기). 대화 미완료면 대화부터 종료. |
| 분석이 오래 걸림 | 그림분석 예산 90s. 콜드스타트 시 첫 분석이 느릴 수 있음 — 시연 전 1회 워밍업 권장. |
| 음성이 안 들림 | 기기 볼륨/무음 해제, 마이크 권한 허용 확인. |
| 리포트 "분석 중" 유지 | 실패 시 **재분석** 버튼 제공 — 재시도. |
| 로그인 실패 | 소셜 콘솔 Redirect URI(`/login/callback/{provider}`) 등록 여부 확인(`외부서비스.md`). |
